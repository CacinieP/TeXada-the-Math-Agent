## 本版变化

- 新增受控词表 `src/texada/core/glossary.py`：24 个术语（格林、高斯、斯托克斯、
  贝叶斯、全概率、华里士、施密特正交化、拉格朗日/罗尔/柯西中值、泰勒、洛必达、
  一阶线性与二阶常系数通解、中心极限、样本方差、欧拉、夹逼、路径无关、
  二项分布、分部积分、牛顿-莱布尼茨、柯西不等式、乘积秩不等式），
  每条都带别名、出处与备注。
- 复用既有确定性快路径（`nl_canonical_concept`），不新增分支：命中即零 token、
  约 12 ms 返回，`/api/convert` 同样先查表。**只有输入就是术语名时才命中**，
  `格林公式和斯托克斯公式的区别`、`泰勒展开式`、带参数的句子仍走模型。
- 每条 LaTeX 必须通过 KaTeX 校验；校验失败自动回退模型路径，绝不返回坏公式。
- 实测（MiniCPM-V 4.7 1B）：真实语料 **31/52 → 47/52**，其中术语名一档
  **5/20 → 20/20**；52 条里 21 条零 token 直出。100 条 golden set 仍为 59/95。
- 评测 runner 现区分"确定性直出"与"模型结果"并单列，避免把查表得分当模型能力。

## 边界

- 词表只覆盖"输入即术语名"（见 `eval/known-gaps.md` G-017）；带参数、复合句、
  含上下文的请求仍在模型路径。
- 词表是受控数据，不抓取、不推断；扩表必须补出处并通过 KaTeX 校验。
- 未改模型、提示词、打包、签名与公证流程。
