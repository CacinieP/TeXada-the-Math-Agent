# v0.4.2 转写边界回归说明

本次修复核对 #35 的三个宿主问题，不重写历史报告或参考答案，也不构成独立人工准确率审核。真实模型输出、原生桌面操作与安装包结果仍须分别记录。

- **T04 漏项**：完整窄句式“x 下标 k 加一”存在下标作用域歧义。运行时只允许 `x_k+1` 或 `x_{k+1}` 这两种完整解释，必须保留 x、k、+1；`x_k` 漏项、改数字/变量或额外项会触发拒绝与有界重试。允许两种解释不表示用户确认了其中一种。冻结的 `eval/transcription_rc1.json` 仍只以 `x_k+1` 评分，另一解释保持严格 `DIFFERENT`。
- **T15 一阶导数记法**：原守卫因预翻译的通用 `\frac` 而误拒 `f'(x)`。新守卫绑定完整请求中的函数、变量和阶数，接受已登记的普通一阶导数记法，仍拒绝偏导、错阶、错变量、自然语言包装或额外项。完整参考登记见 `eval/structure_references.yaml` 的 051；RC 原单一参考不变，合法不同记法不自动改判为严格 MATCH。
- **T10 结构覆盖**：固定 KaTeX 0.18.2 的 `\ne` / `\neq` / `≠` AST 由 HTML 否定叠层与 MathML 不等关系共同组成。现在仅识别完整且类型一致的已知展开；两分支不一致、未知字段或其他 `htmlmathml` 仍为 `UNSUPPORTED`。没有删除否定叠层或忽略一个渲染分支：不等式与等式、变量/数字变化和额外项仍为 `DIFFERENT`。

T17 的 `A^T`、`A^{\top}` 与 `A^{\mathsf T}` 以及二维积分记法，在完整参考登记中已有明确变体与领域条件。严格结构差异、经登记的记法变体和 OCR 真实内容错误需要区分；不修改比较器以隐藏差异，也不借助标准记法推断原图中未见的积分次数、测度或变量。

相关回归位于 `tests/test_operator_drift.py`、`tests/test_structural_match.py`。它们验证拒绝边界和固定 AST 覆盖，不取代最终包推理、真实图片、手写或目标平台验收。

## #40 行内补全的原生桌面验收口径

固定五例分别为 `\frac{a}{|}`、`x^{|}`、`a_{|}`、`\frac{|}{b}+c` 和 `中文😀 \frac{a}{|} 后缀`；`|` 是光标标记，不属于输入。先核对 Ghost Text，再分别验证 Tab 接受只插入建议、Esc 保留原文、Undo 恢复、移动光标或输入后旧响应失效，并记录前后文和零模型调用。完成此真实桌面步骤前，纯函数、API 或 DOM 测试不称作原生交互验收。

前四例接受占位符后可按完整公式检查 compile/render。第五例是中文/emoji 上下文与坐标保真测试：完整混合文本应由公式验证器拒绝，不写成“五例整体 LaTeX 全有效”。接受后保留的数学片段 `\frac{a}{\placeholder{}}` 可单独检查 compile/render，同时如实记录整段文本的拒绝结果。可见渲染和语法通过都不是数学正确性证明。
