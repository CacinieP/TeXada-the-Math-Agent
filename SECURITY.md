# Security Policy / 安全策略

## Supported Versions / 支持版本

| Version | Supported |
|---------|-----------|
| 0.1.x | Yes |
| Older local builds | No |

## Reporting A Vulnerability / 报告漏洞

Please do not open a public issue for vulnerabilities, leaked credentials, signing material, local privilege escalation, installer tampering, or API key handling bugs.

Use GitHub private vulnerability reporting:

https://github.com/CacinieP/TeXada-the-Math-Agent/security/advisories/new

When reporting, include:

- Affected version or commit.
- Operating system and installer type.
- Steps to reproduce.
- Whether the issue affects local Ollama mode, OpenAI-compatible cloud mode, desktop insertion, clipboard handling, or release artifacts.
- Any logs with secrets removed.

## Handling / 处理流程

Security reports are triaged on a best-effort basis. Valid reports will be fixed in the default branch first and then released through the normal desktop release workflow.

请不要在公开 issue 中披露漏洞、泄露的凭据、签名材料、本地权限提升、安装包篡改或 API key 处理问题。

请使用 GitHub 私密漏洞报告：

https://github.com/CacinieP/TeXada-the-Math-Agent/security/advisories/new

报告中请包含：受影响版本或 commit、系统平台和安装包类型、复现步骤、受影响模块，以及已移除密钥的日志。
