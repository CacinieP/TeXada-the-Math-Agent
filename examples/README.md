# TeXada Examples

These examples are short, recorded desktop runs from TeXada v0.3.8. They show
the user input, the Agent path, and the validated output without terminal
windows or edited model responses.

| Example | Input | Output path |
|---------|-------|-------------|
| [Natural language](01-natural-language/README.md) | `probability density function` | Structured LaTeX → compile → render |
| [Image OCR](02-image-ocr/README.md) | Handwritten `∫₀¹ x² dx` | MiniCPM-V candidate → Agent review → render |
| [LaTeX repair](03-latex-repair/README.md) | Incomplete Gaussian PDF | deterministic repair → compile → render |

The combined 30-second tour is embedded at the top of the
[project README](../README.md).
