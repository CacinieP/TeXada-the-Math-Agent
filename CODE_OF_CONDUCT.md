# Code of Conduct / 行为准则

## English

TeXada follows the Contributor Covenant Code of Conduct, version 2.1.

Everyone participating in this project is expected to:

- Be respectful, welcoming, and constructive.
- Focus criticism on ideas and code, not on people.
- Avoid harassment, discrimination, personal attacks, and public or private abuse.
- Respect that TeXada is a math tool used across languages, platforms, and hardware setups.

Unacceptable behavior may be reported through GitHub Issues only when it is not security-sensitive. For private or sensitive reports, use GitHub's private vulnerability reporting or contact the repository maintainer through GitHub.

Maintainers may remove comments, issues, pull requests, or other contributions that violate this code of conduct.

## 中文

TeXada 采用 Contributor Covenant 2.1 版本的行为准则。

参与本项目时，请做到：

- 尊重、友好、建设性地沟通。
- 批评聚焦在想法和代码，而不是人身攻击。
- 不进行骚扰、歧视、辱骂、威胁或公开/私下的恶意行为。
- 尊重不同语言、系统平台和硬件条件下的使用场景。

非安全敏感的问题可以通过 GitHub Issues 报告；涉及隐私、安全漏洞或敏感内容时，请使用 GitHub 私密漏洞报告，或通过 GitHub 联系仓库维护者。

维护者可以移除违反本行为准则的评论、issue、pull request 或其他贡献。
