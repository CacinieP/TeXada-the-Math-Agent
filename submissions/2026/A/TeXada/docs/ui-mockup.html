TeXada 完整用户流程
6 种输入模式 · 4 种输出路径 · VS Code / 剪贴板 / TSF / API 全覆盖
1
唤醒面板
点击菜单栏图标或按 ⌥⌘T 弹出悬浮窗。
自动聚焦输入框，保持上次的 Tab 状态。
⌥⌘T
2
选择模式
按 1-6 切换 Tab：
① NL→LaTeX · ② OCR · ③ 补全
④ 缩写 · ⑤ 历史 · ⑥ 设置
123456
3
输入 (NL 模式)
输入中文/英文数学描述。
实时显示：Intent 分类 + Symbol 预翻译。
按 Enter 发送到 E4B。
EnterShift+Enter
4
输入 (OCR 模式)
拖入图片 / ⌘V 粘贴截图 / 点击选择。
OpenCV 自动预处理(去噪+二值化)。
按 Enter 或自动开始识别。
⌘V⌘⇧4
5
输入 (补全模式)
输入不完整 LaTeX：\sum_{i=1}^{
灰色 ghost text 显示建议补全。
Tab 接受 · Esc 取消。
TabEsc
6
输入 (缩写模式)
输入 shorthand 关键词如 euler。
零模型调用，<1ms 响应。
支持浏览/搜索/添加自定义缩写。
Enter
7
推理 (E4B)
Symbol Engine 预翻译 → 构造 prompt →
Ollama 调用 gemma4:e4b-it-qat。
temperature=0.1 · max_tokens=256。
~0.5-2s 延迟，进度条可视化。
8
验证
KaTeX 解析 → 花括号/环境配对 →
命令合法性检查。
✅ 通过 → 直接输出
🔧 可修复 → LaTeX Fixer 自动修
❌ 不可修复 → 重新调用模型
9
结果展示 (双模式)
顶部模式切换器，⌘K 即时切换：
📐 KaTeX 模式: 视觉公式渲染 → 复制带 $$...$$
📜 纯 LaTeX 模式: 语法结构高亮 → 复制裸 LaTeX
两种模式共享同一 LaTeX 源码
⌘K
10
输出 — 剪贴板
⌘C 一键复制到剪贴板。
默认格式 $$\iint_D f(x,y)\,dx\,dy$$
可在设置中切换为纯 LaTeX (无定界符)。
粘贴到 VS Code → Markdown Preview 直接渲染。
⌘C
11
输出 — VS Code 集成
通过 TSF (Text Services Framework) 协议
直接在光标位置插入 LaTeX。
兼容 Markdown、.tex、Jupyter 等文件。
KaTeX 引擎确保渲染一致。
12
输出 — HTTP API
FastAPI 后端 POST /api/convert
其他应用 (Obsidian/Notion 插件等)
可通过本地 API 调用 TeXada。
返回 JSON: {latex, valid, source, intent}
13
后续操作
复制后：⌘V 粘贴到目标应用
点击「编辑」→ 手动修改 LaTeX 源码
点击「重新生成」→ 换个结果
点击「收藏」→ 保存到自定义缩写库
Esc 关闭面板继续工作
Esc⌘V
14
降级模式
Ollama 离线时：
✅ 缩写库 — 零模型可用
✅ 历史记录 — 可搜索回填
✅ LaTeX 验证 — 纯代码校验
❌ NL/OCR/补全 — 需模型，显示提示
15
双模式输出兼容
📐 KaTeX 模式 → VS Code / Markdown:
• KaTeX 引擎同源，渲染一致
• 复制 $$...$$ → Markdown Preview 直接渲染
• 复制 $...$ → 行内公式
📜 纯 LaTeX 模式 → .tex / LaTeX 编译:
• 复制裸 LaTeX → 粘贴到 .tex 直接可用
• 语法高亮辅助编辑与调试
• 不含 KaTeX 不支持的宏包命令
16
持久化
所有数据本地存储：
• 历史: SQLite (自动清理 >30天)
• 缩写/模板: JSON 文件 (用户可编辑)
• 设置: ~/.texada/config.json
• 零云端 · 零追踪
