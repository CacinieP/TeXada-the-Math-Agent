# Support / 支持

## English

Before opening an issue, check:

- TeXada release notes and README.
- Ollama is installed and running if you use local mode.
- Required models are pulled:

```bash
ollama pull hf.co/openbmb/MiniCPM5-1B-GGUF:Q4_K_M
ollama pull openbmb/minicpm-v4.6:latest
```

Use GitHub Issues for reproducible bugs and feature requests. Include your OS, TeXada version, backend mode, model names, custom Ollama host if used, and screenshots for UI problems.

Do not paste API keys, private endpoint tokens, signing certificates, or personal data into public issues.

## 中文

提交 issue 前，建议先检查：

- TeXada release notes 和 README。
- 如果使用本地模式，Ollama 是否已安装并运行。
- 默认模型是否已拉取：

```bash
ollama pull hf.co/openbmb/MiniCPM5-1B-GGUF:Q4_K_M
ollama pull openbmb/minicpm-v4.6:latest
```

可复现 bug 和功能请求请使用 GitHub Issues。请说明系统、TeXada 版本、后端模式、模型名、是否使用自定义 Ollama 地址，以及 UI 问题截图。

不要在公开 issue 中粘贴 API key、私有 endpoint token、签名证书或个人数据。
